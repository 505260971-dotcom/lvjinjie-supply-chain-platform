# 供应链控制塔 · 线上体验版

> 这是「绿金街供应链项目管理平台」的**纯静态体验版**：无需安装 Python、无需内网、无需任何 API Key，
> 打开网页即可自己点、自己看。

---

## 一、怎么用

打开页面后，有三种进入方式（任选其一）：

| 按钮 | 说明 |
|---|---|
| **一键进入演示（无需联网/后端）** | 业务员视角，推荐先点这个 |
| **进入演示 · 业务部经理** | 经理视角，看团队态势与决策台 |
| 账号 `lijuanyan` / 密码 `88888888` | 演示账号（业务员） |

进入后可点顶部菜单切换 7 个板块：

- **项目资料 Agent** — 资料目录与规范化说明
- **业务台账** — 逐笔订单、收付款、毛利
- **经营数据统计** — 应收、逾期、资金占用费、品牌/型号分布
- **单据完整性核查** — 按日期范围跑一遍单据配套核查
- **资金占用费核算** — 周期与计费明细
- **逾期提醒** — 逾期摘要、风险分级、催款函与飞书演示
- **业务部经理工作台** — 项目组合与决策事项

## 二、重要说明

- 本页所有数据均为**预置快照**（合成演示资产），**不含任何真实业务主体**。
- 问答为**预置示例**；完整能力（实时检索项目资料、DeepSeek 问答、OCR 识别）需在本机部署后使用。
- 写入类操作（确认、关闭、发函、停止供货等）在体验版里为**本地模拟**，不会产生任何效果。
- 顶部若显示「**线上体验版 · 离线演示**」标签，即表示当前离线模式。
